ObeliskPanel - free server manager for ARK: Survival Ascended and ARK: Survival Evolved
=====================================================================================

How to start
------------
1. Unzip this folder anywhere you like (keep all files together).
2. Double-click ObeliskPanel.exe.
3. Allow administrator rights when Windows asks (recommended).

If Windows says that .NET is missing, click "Yes". It opens the official
Microsoft download page for the .NET 10 Desktop Runtime. Install it and
start ObeliskPanel again.

ObeliskPanel checks everything else on start (Visual C++, DirectX,
Amazon certificates) and tells you if something is missing.

What the files are
------------------
ObeliskPanel.exe                  the program, start this one
ObeliskPanel.dll                  the program code
ObeliskPanel.*.json               settings for the .NET runtime
Discord.Net.*.dll                 Discord webhooks and bot
Newtonsoft.Json.dll,
System.*.dll, Microsoft.*.dll     libraries used by Discord.Net

Your settings are stored in %APPDATA%\ObeliskPanel\settings.json.
Source code and help: see the GitHub page this download came from.
